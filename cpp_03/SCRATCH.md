## ex02
The ex introduces the second derived robot class FlagTrap (FragTrap in subject) that inherits from ClapTrap with different default member values and its own special ability highFivesGuys().
- Repetition of the same inheritance pattern from ex01.
- Reinforces the concept of constructor/destructor chaining.
- Shows how multiple similar classes can share a common base.
- Understanding that constructor calls parent constructor, then sets child-specific values.
- Tests improved to verify both copy constructor, copy assignment, and call both classes' special abilities (guardGate for ScavTrap, highFivesGuys for FlagTrap).

## ex03
- Understand Diamond problem in cpp as a inheritance ambiguity problem generated by a hybrid inheritance (hierarchical and multilevel).
- Understand the virtual specifier to guarantee that an instance of that class is created only once.
- Understand the use of operator:: to resolve inheritance ambiguity.
- DiamondTrap has a private `name_` attribute (separate from ClapTrap's `name_`), and must use scope resolution to access the correct one.
- Tests improved to verify all abilities: attack() (from ScavTrap), guardGate() (from ScavTrap), highFivesGuys() (from FlagTrap), and whoAmI() (from DiamondTrap).
- Virtual inheritance requires careful initialization: DiamondTrap must explicitly call ClapTrap's constructor in the initializer list.
